## 执行计划
- 在项目根目录启动一个本地静态服务器，托管 `web/` 目录，以便在浏览器访问 Web UI。
- 服务器端口使用 `5173` 并开启 CORS，确保前端可直接调用喜马拉雅接口（若站点限制跨域，页面会提示凭证与代理方案）。
- 启动后打开预览链接，验证登录、单集解析下载、专辑解析批量下载与设置页面的基本交互。

## 预期结果
- 浏览器打开主页与路由可切换；登录页可保存并验证 `Cookie/BID`；单集与专辑页可展示信息并发起下载；设置页可保存、导入导出配置。
