# 喜马拉雅下载器

一个轻量的喜马拉雅音频下载项目，支持在浏览器中解析与下载单集或整张专辑，提供并发与进度显示，并可管理登录凭证（Cookie/BID）。同时包含浏览器扩展以便在站点中快捷获取凭证。

## 项目组成
- `web/`：零依赖的前端 Web 界面，原生 JS 实现，支持系统自适应浅/深色。
- `core/`：下载与解析的核心逻辑（Node/JS）。
- `web/extension/`：浏览器扩展，用于辅助获取 Cookie 与 BID。
- `utils/`、`tests/`：通用工具与基础测试。

## 特性
- 单集下载与专辑批量下载，支持并发与失败重试。
- 音质选择与基本配置管理（导入/导出）。
- 登录凭证验证（仅本地保存）。
- 现代化 Web 界面，自动适配白天/黑夜模式。
